## 2. TiltEffect 角度 / 压深表 `[推算]`（常量 `[文档]`）

`MaxAngle = 0.3` 弧度 = **17.1887°**；`MaxDepression = 25` px。

```
angleMagnitude = |nx-0.5| + |ny-0.5|                 // 0..1
angle_deg      = angleMagnitude * 17.1887338
xAngleContrib  = |nx-0.5| / angleMagnitude
RotationY      = angle_deg * xAngleContrib * (-sign(nx-0.5))
RotationX      = angle_deg * (1 - xAngleContrib) * (+sign(ny-0.5))
GlobalOffsetZ  = -(1 - angleMagnitude) * 25
```

| 点击位置 (nx, ny) | angleMagnitude | 总转角 deg | RotationY deg | RotationX deg | 压深 px |
|---|---|---|---|---|---|
| (0.50, 0.50) 正中 | 0.000 | 0.0000 | +0.0000 | +0.0000 | 25.00 |
| (1.00, 0.50) 右边缘中点 | 0.500 | 8.5944 | -8.5944 | -0.0000 | 12.50 |
| (0.50, 1.00) 下边缘中点 | 0.500 | 8.5944 | +0.0000 | +8.5944 | 12.50 |
| (0.00, 0.00) 左上角 | 1.000 | 17.1887 | +8.5944 | -8.5944 | 0.00 |
| (1.00, 1.00) 右下角 | 1.000 | 17.1887 | -8.5944 | +8.5944 | 0.00 |
| (0.25, 0.75) 四分点 | 0.500 | 8.5944 | +4.2972 | +4.2972 | 12.50 |

**关键结论：这个动画没有单一转轴，也没有固定总转角。**
转轴由点击位置决定（水平偏移分给 RotationY，垂直偏移分给 RotationX），
总转角在 0° ~ 17.1887° 之间连续变化；点正中时**完全不旋转**。

## 3. 透视强度表 `[推算]`

CSS 式透视下，绕竖直中轴旋转 θ 时：

```
h_near / h_far = (k + sin(θ)/2) / (k - sin(θ)/2)     其中 k = 相机距离 P / 磁贴宽度 W
```

| k = P/W | θ=4.000° | θ=8.594° | θ=12.000° | θ=17.189° |
|---|---|---|---|---|
| 0.500 | 1.1500 | 1.3514 | 1.5250 | 1.8390 |
| 0.655 | 1.1125 | 1.2575 | 1.3773 | 1.5826 |
| 1.000 | 1.0723 | 1.1615 | 1.2320 | 1.3468 |
| 1.500 | 1.0476 | 1.1048 | 1.1489 | 1.2185 |
| 2.000 | 1.0355 | 1.0776 | 1.1097 | 1.1595 |
| 2.730 | 1.0259 | 1.0563 | 1.0792 | 1.1144 |
| 3.000 | 1.0235 | 1.0511 | 1.0718 | 1.1036 |
| 4.000 | 1.0176 | 1.0381 | 1.0534 | 1.0767 |
| 5.000 | 1.0140 | 1.0303 | 1.0425 | 1.0609 |
| 8.000 | 1.0088 | 1.0189 | 1.0263 | 1.0376 |

反解：要达到某个近/远比 r，需要 `k = sin(θ)/2 * (r+1)/(r-1)`。

| 目标近/远比 | 需要在 θ=17.1887° 时的 k | 相当于 CSS perspective（磁贴宽 200px 时）|
|---|---|---|
| 1.050 | 6.0582 | 1212 px |
| 1.100 | 3.1030 | 621 px |
| 1.200 | 1.6254 | 325 px |
| 1.350 | 0.9921 | 198 px |
| 1.582 | 0.6555 | 131 px |
| 2.000 | 0.4433 | 89 px |
| 3.000 | 0.2955 | 59 px |

**这张表直接回答了「透视强度」：**

- θ 最大只有 17.1887°，即使相机贴到 k=1（相机距离 = 1 倍磁贴宽），近/远比也只有 **1.3468**。
- 常见的 CSS `perspective` 落在 k≈3~8，对应近/远比 **1.1036 ~ 1.0376**，肉眼几乎看不出透视。
- 参照：本项目现有实现 `docs/flip-baseline.md` 的交接点近/远比是 **1.582**，
  反解出等效 k = **0.6555**，即相机距离只有 **131 px**（按 200px 磁贴宽）——
  这比 Win8 在最大倾角下的透视**还要强得多**。

## 4. 旋转引起的宽度收缩 `[推算]`

| θ deg | 轮廓宽度 / 原宽 (k=2) | cos θ |
|---|---|---|
| 0.000 | 1.00000 | 1.00000 |
| 4.000 | 0.99787 | 0.99756 |
| 8.594 | 0.99015 | 0.98877 |
| 12.000 | 0.98080 | 0.97815 |
| 17.189 | 0.96058 | 0.95534 |

区别很小（cos 与透视项互相抵消一部分），所以**从轮廓宽度反解转角是可行的**，
但精度依赖对 k 的假定；`probe` 模式因此同时输出 `h_left`/`h_right`/`w` 三个原始量，
让使用者自己选反解路径。
