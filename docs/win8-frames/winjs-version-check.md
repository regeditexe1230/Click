# WinJS 跨版本常量核对

本文件由 `docs/win8-frames/_vercheck.py` 生成。

**目的**：`docs/win8-tile-spec.md` 的常量取自 `winjs@4.4.3`（约 Windows 10 时代，2017-03 发布）。本任务的目标是 **Windows 8**，所以必须确认这些常量在更早的版本里是否一致。

npm 上最早的 `winjs` 是 **3.0.0**（2014-09-16，Windows 8.1 Update / Windows Phone 8.1 时代）。**WinJS 1.0 / 2.0（Windows 8 RTM / 8.1）从未发布到 npm**，因此本次无法用 npm 通道核对 —— 这是本核对的一个明确的覆盖盲区，如实记录。
