### 几何模型

旋转轴在页面 `x = −40px`（视口左边缘再往左 40px），
整页左边缘距轴 `d_left = 40px`，右边缘距轴 `d_right = 视口宽 + 40px`。

```
rotateY(θ)：距轴 d 的竖直直线 →  x' = d·cosθ ,  z = −d·sinθ
CSS perspective(P) 的缩放：      s(d) = P / (P − z) = P / (P + d·sinθ)
竖直方向只受 s 影响，故：        h(d) = H · s(d)
近边 = 左边缘(d=40)，远边 = 右边缘(d=宽+40)
```

下表按 **视口宽 480px** 计算。换视口宽只需改本脚本顶部的 `VIEWPORT_W`。

## 3. 与 TiltEffect / 本项目现状的对照

| 场景 | 透视距离 | 转角 | 左边缘高度 | 右边缘高度 | **近/远比** |
|---|---|---|---|---|---|
| turnstile 进场起始 | 600 px | +80° | 0.9384 | 0.5395 | **1.7393** |
| turnstile 退场结束 | 600 px | −50° | 1.0538 | 2.9754 | **2.8234** |
| turnstile 任意终点 | 600 px | 0° | 1.0000 | 1.0000 | **1.0000**（无畸变） |
| TiltEffect 极限 | 未公开 | 17.1887° | — | — | **≈1.35**（绕自身中心，透视极弱） |
| 本项目现状（翻转） | 等效 131 px | — | — | — | **1.582** |


**结论：Win8 里透视强度差异极大，取决于动画种类。**
- **磁贴按压（TiltEffect）**：绕自身中心转 ≤17.19°，透视极弱（≤1.35）
- **页面转场（turnstile）**：绕屏幕外 40px 的轴转 80°，透视极强（进场起始 **1.7393**）

本项目如果要做「和 Win8 磁贴动画一模一样」的进出效果，**对应的就是 turnstile**，透视不但不该减弱，反而应该用 `perspective(600px)` 并把旋转轴放到容器外侧。

### 脚注 1：为什么退场那一行没有数值
在 `perspective(600px)` 下把**整屏宽**元素绕屏幕外 40px 的竖轴转 −50°，右边缘的 z 位移达到 `(W+40)·sin50° ≈ 1077px`，**已经超过相机距离 600px**，即那部分转到了相机平面背后，透视投影无定义。

不越过相机平面的最大元素宽度：**−50° 时 743px**；+80° 恒有效，无宽度上限。
公式：θ<0 时 `W_max = P/|sinθ| − 40`。

**这条本身就是一条有用的推断 [推测]：** 官方 turnstile 连整屏宽的页面都这么写，说明它的典型使用对象是**接近整屏宽的元素**，而真实运行时浏览器会在相机平面处裁剪，−50° 只出现在**元素已经淡出到 opacity 0 的那 128ms 里**（`turnstileForwardOut` 的 opacity 用 `cubic-bezier(1,-0.42,0.995,-0.425)` 压到很晚才归零），所以人眼看不到穿帮。
**复刻时的含义：退场不要单独把 −50° 当可见关键帧来调，它必须和快速淡出绑定。**

## 4. `continuum` 对照（无 perspective！）

`continuumForwardIn` 是**三段式**，逐字抄自 L14 起：

| 作用对象 | 变换 | duration | timing |
|---|---|---|---|
| `incomingPage` | `scale(0.5,0.5)` → `scale(1.0,1.0)` | 350 | `cubic-bezier(0.33, 0.18, 0.11, 1)` |
| `incomingItemRoot` | `translate(0px, 225px)` → `translate(0px, 0px)` | 350 | `cubic-bezier(0.24,1.15,0.11,1.1575)` |
| `incomingItemContent` | `rotateX(80deg) scale(1.5,1.5)` → `rotateX(0deg) scale(1.0,1.0)` | 350 | `cubic-bezier(0,0.62,0.8225,0.9625)` |
| 以上每段的 `opacity` | `0` → `1` | 350 | `cubic-bezier(0, 2, 0, 2)` |

`incomingItemContent` 的旋转原点：`animRotationTransform(incomingItemContent, { ltr: "0px 50%", rtl: "100% 50%" }, ...)` —— **左边缘、垂直中心**。

**关键差异：continuum 的 transform 串里没有 `perspective(...)`，turnstile 的串里有 `perspective(600px)`。**
所以在 Win8 的转场族里，**continuum 绕元素的横向中轴翻（X 轴、无透视畸变），turnstile 绕屏幕外的竖直轴转（Y 轴、有 600px 透视）** —— 两者是正交的两套「进出」语言。
